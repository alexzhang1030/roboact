# 第一期预先写好的节点清单 v0（草稿，待 Alex 过目）

起草：Fadell · PRD　日期：2026-10-31
依据：PRD v1.2.1。节点都由我们预先写好，用户在画布里只选节点、连线、填参数。副作用标记：none 纯计算 / read 读外部 / write 写外部（见 PRD 第 5 节）。

| 节点 | 用户拿它做什么 | 输入 | 输出 | 副作用 |
|---|---|---|---|---|
| 开始 | 流程入口，填这次运行的初始数据 | 无 | 初始数据 | none |
| 输出 | 流程的最终结果，跑完在右侧面板显示 | 任意 | 无 | none |
| 常量 | 放一段固定文本或数值，供下游使用 | 无 | 值 | none |
| 文本模板 | 把几路输入拼成一段提示词 | 多路文本 | 文本 | none |
| 模型调用 | 调一次大模型，拿回回复 | 提示词、可选的历史消息 | 回复文本、工具调用请求 | read |
| 工具调用 | 执行模型要求的一个工具，结果交回给模型 | 工具名、参数 | 工具结果 | 由所调的工具决定 |
| 条件判断 | 按输入字段做简单比较，走「是」或「否」；环的出口用它 | 任意 | 是 / 否两路 | none |
| 合并 | 等几路输入都到齐再往下传 | 多路 | 合并后的数据 | none |
| 人工确认 | 跑到这里暂停，等人点「通过」或「驳回」 | 任意 | 通过 / 驳回两路 | none |

要 Alex 定的：
1. 这份清单够不够第一期，有没有要删的。
2. 「工具调用」第一期接哪些工具。工具清单决定副作用标记，标错会导致重放时真的再执行一次。
3. 是否要接机器人那边的数据源或执行器（例如收发消息、调用机器人接口）。要的话请给出接口名单，我不自己猜。
4. 「人工确认」和断点作用不同：断点是调试时停，人工确认是正式运行里也要停。第一期要不要。
